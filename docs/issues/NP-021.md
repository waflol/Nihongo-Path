## Bằng chứng (23/11/2026, Chrome thật qua ngrok, admin@test.vn)
File: `語彙 徹底トレーニング.pdf` (PDF có lớp text, 5134 dòng) → bộ test "TEST NP-021 (xoá sau)".
- Đọc file + tự ánh xạ cột (Chữ Hán / Âm Hán / Cách đọc / Ý nghĩa): OK.
- Xem trước gồm AI kiểm tra 600 thẻ trong **cùng một request** (~13 phút): **4861 hợp lệ, 273 trùng, 0 lỗi** (= 5134 dòng).
- Bấm **Xác nhận**: "Nhập thành công: 4861 thẻ mới", bỏ qua 273 trùng.
- Chạy lại đúng file đó: **0 hợp lệ, 5134 trùng, 0 lỗi**, nút "Xác nhận nhập 0 thẻ" bị khóa → không tạo thẻ trùng.
- Lỗi gặp lần đầu: request xem trước dài bị gateway cắt 503 và mất kết quả → đã sửa ở commit `7d91aad` (server giữ kết quả theo task, wizard tự lấy lại); lần chạy sau không còn lỗi.
